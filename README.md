# mip2025

проект 8: переход однозвенного маятника в заданное положение за заданное время с использованием линеаризации обратной связью и интерполяцией полиномом пятого порядка.

В файле `pendulum.py` маятник переводится из `theta0 = 0.1` рад в `thetad = 1.0` рад за `T = 2` с.

Заданная траектория строится через полином пятого порядка из главы 9 Modern Robotics:

```text
s(t) = 10r^3 - 15r^4 + 6r^5,  r = t / T
theta_ref(t) = theta0 + s(t) * (thetad - theta0)
```

Такой полином дает нулевую скорость и нулевое ускорение в начале и в конце движения.

Для управления используется линеаризация обратной связью. Модель маятника:

```text
ddtheta = -g/L * sin(theta) + tau/(m*L^2)
```

Момент выбран так:

```text
tau = m*L^2 * (g/L * sin(theta) + u)
u = acc_ref - kp * e - kd * de
```

После компенсации нелинейной части получается `ddtheta = u`, поэтому маятник отслеживает заданную траекторию.
Момент `tau` подается в PyBullet в режиме `TORQUE_CONTROL`.

Запуск:

```bash
pip install -r requirements.txt
python pendulum.py
```

Ожидаемый результат: синяя траектория положения почти совпадает с красной заданной траекторией,
ошибка к моменту T = 2 с близка к нулю, после этого маятник удерживается около 1 рад.
